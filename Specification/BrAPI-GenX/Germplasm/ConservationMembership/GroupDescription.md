# Group ConservationMembership

**Status:** BrAPI-GenX **STRUCTURAL_DRAFT** candidate under Request for Comments (RFC) 102. This is neither an approved accession exchange standard nor a verified persistent service.

The proposed resource has immutable, namespaced registration and optional status-filtered retrieval. Proposed duplicate replay and changed-content conflict are not independently proven. Official BrAPI Germplasm and MCPD records already describe accession and institute context. A conservation-program membership may be a distinct workflow, but this draft currently stores only optional `memberDbId` and free-form `program` strings, without typed identity, consent, custody, or a verified conservation obligation. Required namespaced `conservationMembershipDbId` and `status` coexist with optional `memberDbId`, `program`, `supersedes` and provenance. A free-form member string is not a validated Germplasm/Accession identity and the candidate has no typed GenX CollectingMission link (D-306). Requiredness of member and program remains D-304–D-305.

**Boundaries:** The existing official Breeding Application Programming Interface (BrAPI) version 2.1 Germplasm and Multi-Crop Passport Descriptors (MCPD) contracts remain authoritative. Metadata registration does not establish accession ownership, field-collection validity, genetic identity, physical custody, legally valid conservation membership, or verified exchange transformation. Links among draft resources remain unratified until their identifiers, authorities and semantics have evidence.
