# Group McpdAdapter

**Status:** BrAPI-GenX **STRUCTURAL_DRAFT** candidate under Request for Comments (RFC) 103. This is neither an approved accession exchange standard nor a verified persistent service.

The proposed resource has immutable, namespaced registration and optional status-filtered retrieval. Proposed duplicate replay and changed-content conflict are not independently proven. Official BrAPI version 2.1 already provides `GET /brapi/v2/germplasm/{germplasmDbId}/mcpd` and a GermplasmMCPD schema. This candidate adapter record includes only an optional source string and provenance; it does not execute a transform, define a verified data mapping, or replace the official MCPD representation. The draft requires only namespaced `mcpdAdapterDbId` and lifecycle `status`. Optional `source`, `supersedes` and provenance do not define a data converter, adapter implementation, source schema version, validation report or typed Germplasm reference. A separate adapter identity needs independent evidence. The source requiredness (D-307), typed Germplasm linkage (D-308), and GenX Crosswalk linkage (D-309) remain open.

**Boundaries:** The existing official Breeding Application Programming Interface (BrAPI) version 2.1 Germplasm and Multi-Crop Passport Descriptors (MCPD) contracts remain authoritative. Metadata registration does not establish accession ownership, field-collection validity, genetic identity, physical custody, legally valid conservation membership, or verified exchange transformation. Links among draft resources remain unratified until their identifiers, authorities and semantics have evidence.
