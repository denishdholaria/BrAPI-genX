# Group CollectingMission

**Status:** BrAPI-GenX **STRUCTURAL_DRAFT** candidate under Request for Comments (RFC) 101. This is neither an approved accession exchange standard nor a verified persistent service.

The proposed resource has immutable, namespaced registration and optional status-filtered retrieval. Proposed duplicate replay and changed-content conflict are not independently proven. Official BrAPI version 2.1 Germplasm Multi-Crop Passport Descriptors (MCPD) data already includes `collectingMissionIdentifier`. This draft proposes a separate CollectingMission metadata record, but it does not establish a typed germplasm membership, mission participants, expedition provenance or a demonstrated need for a new identifier. Only namespaced `collectingMissionDbId` and lifecycle `status` are required; `title`, `supersedes` and provenance are optional. Official MCPD data already has collecting-mission identifiers on germplasm records. This draft has no typed Germplasm reference (D-302) or GenX ResearchProgram reference (D-303). Whether the title is required remains D-301.

**Boundaries:** The existing official Breeding Application Programming Interface (BrAPI) version 2.1 Germplasm and Multi-Crop Passport Descriptors (MCPD) contracts remain authoritative. Metadata registration does not establish accession ownership, field-collection validity, genetic identity, physical custody, legally valid conservation membership, or verified exchange transformation. Links among draft resources remain unratified until their identifiers, authorities and semantics have evidence.
