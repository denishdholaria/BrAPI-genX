# Group GenomicPrediction

**Status:** BrAPI-GenX **STRUCTURAL_DRAFT** candidate under Request for Comments (RFC) 054. This proposed genomic prediction result is not a validated genomic estimated breeding value (GEBV), scientifically calibrated predictor, or official Breeding Application Programming Interface (BrAPI) version 2.1 data resource.

The response schema requires `genomicPredictionDbId`, `analysisMethodDbId`, and lifecycle `status`; the registration request requires only `genomicPredictionDbId` and `analysisMethodDbId`. `predictions`, `accuracy`, `traitDbId`, `studyDbId`, `jobDbId`, and `provenance` are optional. `predictions` is an unconstrained object described as keyed by germplasm identifiers, without typed values, mandatory records, trait units, genetic-base reference, uncertainty intervals, or validated germplasm joins. `accuracy` is a number with no range, estimation protocol, cross-validation design, reference population, or out-of-sample evidence mandated by the schema.

**Scientific boundary:** Prediction values cannot be assumed to represent a particular breeding-value scale or comparable genotype effects across training populations or traits. A reported accuracy value does not prove predictive accuracy, transportability, sample independence, or lack of data leakage. The required `analysisMethodDbId` is a string and does not bind an exact `methodVersion` or validate execution. No `genomicDatasetDbId` is modelled, notwithstanding deferred D-161; D-160–D-162 remain unresolved. A candidate prediction record is not a breeding selection verdict and its registration does not constitute approval or validated runtime replay.
