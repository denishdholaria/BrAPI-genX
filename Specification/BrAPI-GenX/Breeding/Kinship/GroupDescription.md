# Group Kinship

**Status:** BrAPI-GenX **STRUCTURAL_DRAFT** candidate under Request for Comments (RFC) 052. `KinshipMatrix` is a proposed matrix-registration metadata record, not proof that a scientifically interpretable kinship matrix was computed, stored, validated or made accessible.

The response schema requires `kinshipMatrixDbId`, `analysisMethodDbId` and lifecycle `status`; the registration request requires only `kinshipMatrixDbId` and `analysisMethodDbId`. `matrixRef`, `matrixDigest`, `jobDbId`, `studyDbId` and `provenance` are optional. No matrix shape, sample-ordering metadata, reference population, relationship scale, allele-frequency convention, computation method version, genotype/pedigree derivation, symmetry or positive-semidefiniteness validation is required.

**Scientific and integrity boundary:** `matrixRef` is an optional storage-location string, not an accessible or content-verified payload. `matrixDigest` is an optional string described as SHA-256 (Secure Hash Algorithm 256-bit), without an enforced digest pattern, byte canonicalization convention or verification result. The schema does not prove matrix existence or identity and cannot establish equivalence to a GenX `GenomicRelationship` record, nor a pedigree-derived coefficient. A required `analysisMethodDbId` string does not bind an exact `methodVersion` or prove execution. No `genomicDatasetDbId` field is modelled; D-154–D-156 remain deferred. Proposed immutable replay is not independent persistent-service evidence.
