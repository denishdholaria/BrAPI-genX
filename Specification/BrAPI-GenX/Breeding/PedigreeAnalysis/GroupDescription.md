# Group PedigreeAnalysis

**Status:** BrAPI-GenX **STRUCTURAL_DRAFT** candidate under Request for Comments (RFC) 060. `PedigreeAnalysis` proposes a record for pedigree-derived analysis metadata and must not be confused with authoritative Breeding Application Programming Interface (BrAPI) version 2.1 Germplasm relationships or a validated inbreeding/kinship calculation.

The response schema requires `pedigreeAnalysisDbId`, `analysisMethodDbId` and lifecycle `status`; the registration request requires only `pedigreeAnalysisDbId` and `analysisMethodDbId`. `pedigreeMetrics`, `studyDbId`, `jobDbId` and `provenance` are optional. `pedigreeMetrics` is an unconstrained object without mandatory inbreeding coefficients, parent identities, ancestor depth, pedigree completeness, base population, uncertainty, method version, or genetic assumptions.

**Scientific boundary:** An arbitrary metrics map does not establish biological parentage, pedigree completeness, relatedness accuracy or a defensible inbreeding coefficient. No exact `methodVersion` is required, and `analysisMethodDbId` is an unverified string. Kinship based on ancestry and genomic relatedness inferred from variants may use different estimands and are not interchangeable by similar names. Official BrAPI Germplasm identities and ancestry remain authoritative. No `genomicDatasetDbId` field is modelled; D-178–D-180 remain deferred. A record is not proof of accepted scientific evaluation, access authorization or persistent replay.
