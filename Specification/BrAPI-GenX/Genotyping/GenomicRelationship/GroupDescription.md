# Group GenomicRelationship

**Status:** BrAPI-GenX **STRUCTURAL_DRAFT** candidate under Request for Comments (RFC) 056. `GenomicRelationship` proposes metadata for a genomic relationship matrix; registration does not establish that a well-defined pairwise relationship coefficient set exists or is comparable with other matrices.

The response schema requires `genomicRelationshipDbId`, `analysisMethodDbId` and lifecycle `status`; registration requires only `genomicRelationshipDbId` and `analysisMethodDbId`. Optional `matrixRef`, `digest`, `jobDbId`, `studyDbId` and `provenance` are all non-required. There is no mandatory germplasm/sample order, genotype panel reference, allele-frequency baseline, ploidy, relatedness estimator, matrix dimensionality, coordinate system, matrix value validation or serialization contract.

**Scientific and integrity boundary:** An optional matrix-location string and opaque digest do not verify content existence or reproducibility; the digest field has no algorithm or structured format requirement. Even an accessible payload would need sample identities, an exact computation method/version and an explicit estimator to support scientific comparisons. Do not infer that this candidate is a scientific alias or wire-compatible substitute for `KinshipMatrix` or a pedigree-derived relationship. The `analysisMethodDbId` value is not a validated authority-matched method-version join. No `genomicDatasetDbId` is modelled, despite D-167; D-166–D-168 remain unresolved.
