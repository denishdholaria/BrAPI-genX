# Group GenomicDatasets

**Status:** BrAPI-GenX **STRUCTURAL_DRAFT** candidate under Request for Comments (RFC) 013. The candidate dataset register is not an official Breeding Application Programming Interface (BrAPI) version 2.1 VariantSet or CallSet and is not an independently verified data repository.

The proposed GenomicDataset response requires genomicDatasetDbId, datasetName, datasetType, free-text referenceAssembly and lifecycle status. The request does not require status. pipelineName, pipelineVersion, inputDigest, outputDigest, sampleCount, variantCount, accessPolicy and releaseStatus are optional metadata. The current schema contains no variantSetDbId, callSetDbId, variantMatrixDbId, typed ReferenceSet reference, data-file retrieval address or access-control rule. It cannot prove a join to official BrAPI v2.1 resources, successful pipeline execution or identity of the underlying genomic records.

**Lineage, integrity and access boundary:** A SHA-256 (Secure Hash Algorithm 256-bit) example in a free-form string is not a checked digest or canonical input definition. A releaseStatus value does not establish archive publication; an accessPolicy value does not implement authorization. An assembly name is not a verified mapping to official ReferenceSet. D-36–D-38 remain open. The proposed immutable revision, retry and release semantics are not established by independent authenticated storage evidence; advisory operation neighbors are not normative links.
