# Group CarbonStock

**Status:** BrAPI-GenX **STRUCTURAL_DRAFT** candidate under Request for Comments (RFC) 067. `CarbonStock` proposes an immutable record that may describe carbon in soil, biomass, litter or coarse woody debris. Registering this record does **not** verify a measured carbon stock, a carbon sequestration outcome, a reduction in emissions, an accredited inventory or a tradable carbon credit.

The registration request requires **only** `carbonStockDbId`; the response adds lifecycle `status` as required. `studyDbId`, `locationDbId`, `pool`, numeric `stockMgPerHa` (megagrams per hectare), numeric `depthCm` (centimetres), date-time `measuredAt`, `supersedes` and `provenance` are all optional. `pool` has a fixed enum (`soil`, `biomass`, `litter`, `coarse-woody-debris`) but is itself optional. There is no condition requiring soil depth for soil stocks; no pool-specific stock calculation; no required location, area, sampling design, bulk density, dry-mass basis, laboratory method, uncertainty, model version, or measured/modelled distinction. A `stockMgPerHa` field name specifies a nominal unit, not scientifically verified carbon comparability.

**Standards and relationships:** Official Breeding Application Programming Interface (BrAPI) version 2.1 Observations can represent recorded values with optional Study and observation-unit context, but this draft is not an official Observation. The optional `studyDbId` and `locationDbId` strings are not authority-checked links. No explicit GenX Telemetry or AnalysisResult identifier is defined; optional provenance is not itself scientific accreditation. A nominal carbon-stock record does not prove a carbon flux or an emissions offset.

**Deferred questions:** D-199 asks whether the numeric stock should be required (currently optional); D-200 asks whether soil/litter depth is required (currently optional for all pools); D-201 asks about modelled-source links (no typed Telemetry or AnalysisResult link exists). These decisions remain open.
