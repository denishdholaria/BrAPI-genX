# Group SoilProfile

**Status:** BrAPI-GenX **STRUCTURAL_DRAFT** candidate under Request for Comments (RFC) 023; not an independently validated environmental data product or official Breeding Application Programming Interface (BrAPI) version 2.1 resource.

This group proposes registered, namespaced environmental metadata with immutable revisions and read/list operations. Its replay and changed-body conflict contract remains candidate behavior, not evidence of a deployed persistent scientific service. The candidate requires namespaced `soilProfileDbId`, `locationDbId`, `sampledAt`, and `status`. Soil texture, pH, organic matter, moisture, nutrient values and units are optional or partly unstructured. Critically, no sampling depth or depth interval is represented (D-68); nutrient kinds and units are not governed and there is no typed WeatherObservation linkage (D-66–D-67).

**Boundaries:** A single dated soil profile metadata record does not establish a soil horizon, depth-specific laboratory result, bulk density, standardized moisture basis, or certified nutrient measurement. Official BrAPI Location still supplies geographical context, but string references do not verify sample provenance. The draft has no typed WeatherObservation link (D-67). A named Location, station, variable, scientific interval or data source does not itself prove an authenticated observation, reproducible model computation, accepted uncertainty, correct units or verified environmental provenance. Advisory endpoint neighbors are not typed source-data lineage. Outstanding decision D-67 and associated domain requirements remain explicitly unresolved.
