# Group ClimateNormals

**Status:** BrAPI-GenX **STRUCTURAL_DRAFT** candidate under Request for Comments (RFC) 033; not an independently validated environmental data product or official Breeding Application Programming Interface (BrAPI) version 2.1 resource.

This group proposes registered, namespaced environmental metadata with immutable revisions and read/list operations. Its replay and changed-body conflict contract remains candidate behavior, not evidence of a deployed persistent scientific service. The draft requires namespaced `climateNormalDbId`, `locationDbId`, string `period`, variable identifier, numeric `mean`, and `status`; `min`, `max`, unit and provenance are optional. There is no controlled statistical aggregation method, data completeness or quality measure, month/season definition, validated climate reference period, or typed WeatherObservation link (D-96–D-98).

**Boundaries:** An entered climate normal is a long-term statistic, not a single environmental observation or a forecast. Required `period` is a free-form string, and the draft supplies no evidence of the source measurements or computation. No typed WeatherObservation reference is defined (D-97). A named Location, station, variable, scientific interval or data source does not itself prove an authenticated observation, reproducible model computation, accepted uncertainty, correct units or verified environmental provenance. Advisory endpoint neighbors are not typed source-data lineage. Outstanding decision D-97 and associated domain requirements remain explicitly unresolved.
