# Group WeatherObservations

**Status:** BrAPI-GenX **STRUCTURAL_DRAFT** candidate under Request for Comments (RFC) 010; not an independently validated environmental data product or official Breeding Application Programming Interface (BrAPI) version 2.1 resource.

This group proposes registered, namespaced environmental metadata with immutable revisions and read/list operations. Its replay and changed-body conflict contract remains candidate behavior, not evidence of a deployed persistent scientific service. The draft requires namespaced `weatherObservationDbId`, `observedAt`, and `measurements`. Each measurement has a string variable identifier and required numerical value, with optional unit. `stationDbId`, `locationDbId`, qualityFlag, provenance and status are optional. The array may be empty, there is no enforced station-to-location relationship, and no conditional missingness behavior despite qualityFlag permitting `missing` (D-27–D-29).

**Boundaries:** Official BrAPI version 2.1 provides Locations, Observation Variables and Observations. The draft GenX WeatherObservation is a separate environmental series of numeric measurements, but named variable/location strings do not prove resolved references or valid sensor quality. It does not automatically become an official BrAPI scientific Observation. A named Location, station, variable, scientific interval or data source does not itself prove an authenticated observation, reproducible model computation, accepted uncertainty, correct units or verified environmental provenance. Advisory endpoint neighbors are not typed source-data lineage. Outstanding decision D-27 and associated domain requirements remain explicitly unresolved.
