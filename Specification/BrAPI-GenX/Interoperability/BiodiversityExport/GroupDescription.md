# Group BiodiversityExport

**Status:** BrAPI-GenX **STRUCTURAL_DRAFT** candidate under Request for Comments (RFC) 121. `BiodiversityExport` proposes a registered descriptor of a possible specimen or occurrence export, not a transfer of biodiversity data, an accepted taxonomic record, an archive, or independently verified publication to the Global Biodiversity Information Facility (GBIF).

Registration requires **only** `biodiversityExportDbId`; the response additionally requires lifecycle `status`. `specimenType`, `occurrenceId`, `collectionDate`, `location`, `taxon`, `supersedes` and `provenance` are all optional. `collectionDate` is an unformatted string; location and taxon are unstructured strings, and the occurrence identifier is not a validated persistent identity. Nothing requires a specimen, resolved taxonomic name, collection event, coordinates or evidence of a lawful exchange. The `status` values `active`, `superseded`, `withdrawn` represent record lifecycle, **not delivery or acceptance status**.

**Interoperability limit:** The typed schemas define no Darwin Core Archive payload or mapping, source dataset identity, `basisOfRecord`, geospatial coordinates, publisher identifier, archival file address/digest, license or access policy, export destination, delivery receipt or external publication status. A namespaced export-record identifier is not an occurrence identifier issued or accepted by an external network. The current operations register/list/retrieve metadata rather than export bytes or publish a Darwin Core occurrence dataset. No conformant Darwin Core Archive or GBIF publishing workflow is demonstrated by this record.

**Overlap and authority:** Official Breeding Application Programming Interface (BrAPI) version 2.1 Germplasm Multi-Crop Passport Descriptors metadata already captures collecting-context information; GenX `FAIRPackage` separately proposes data-exchange payload references. This new draft has neither a typed `germplasmDbId` relationship nor an approved crosswalk to either resource. It cannot establish a taxon's accepted identity, a collection's legal permissions, georeference accuracy or data license.

**Deferred decisions:** D-361 asks whether `occurrenceId` must be required (currently optional); D-362 whether `taxon` requires controlled terminology (currently free text); D-363 whether to link GenX `ResearchAsset` (no such property is modelled). These remain unratified.
