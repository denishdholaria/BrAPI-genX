# Group Project

**Status:** BrAPI-GenX **STRUCTURAL_DRAFT** candidate/proposed research reference, not an accepted official Breeding Application Programming Interface (BrAPI) version 2.1 resource or independently verified service. 

The historical/draft `Project` metadata record defines a namespaced identifier, required lifecycle status, and optional name or descriptive data, `supersedes` and provenance. Existing proposed register/list/retrieve files must not be interpreted as accepted interoperability or persistent runtime conformance.

**Scope and reference-identity boundaries:** The optional title and funding are free strings without grant authority, organizational ownership, funding commitment, verified study association or lifecycle of awards. The candidate has no typed BrAPI Study or GenX ResearchAsset identifier. A research project label is not proof that a study or grant exists. Decisions D-265 and the remaining RFC questions are not resolved by an operation's existence. Advisory links are navigation only, not typed or legally authorized scientific relationships.
