## Open API files required for generation from JSON Specification 

These files are required for the generation of OpenAPI specification
from the JSON Specification. These are copies of those in the 
[Components](../Components) directory, so should be removed in the future when the
Schema tools are improved.

This is a **legacy generation input**, not a second authoritative set of
BrAPI or GenX semantic definitions. The upstream schema-tool dependency must
be removed and tested before any consolidation; see decision D-04 for the
separately deferred GenX build integration.
